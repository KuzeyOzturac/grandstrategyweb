# World Atlas

An interactive map of countries and first-level administrative regions. Search for a country or state/province, select a shape to inspect its owner, and pan and zoom the map. There is no gameplay or simulation.

## Run locally

```sh
npm ci
npm run dev
```

Run `npm run check`, `npm run build`, and `npm run test:e2e` to verify the app.

## Map data

`public/data/world.json` contains Natural Earth 110m country boundaries. `public/data/states.json` contains simplified Natural Earth 10m administrative level 1 boundaries. Each region's `country` is copied from the source `adm0_a3` field; `countryName` comes from the matching country or the source `admin` field. See [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) for its public-domain terms. Boundaries are cartographic approximations; disputed territories may differ by source. This atlas does not assert a position on disputed sovereignty.

The state dataset is generated by `scripts/prepare_atlas.py` from `ne_10m_admin_1_states_provinces.geojson` in the parent work directory; the script downloads it there if absent. The source is downloaded during data preparation only. The deployed app makes no external data requests.
