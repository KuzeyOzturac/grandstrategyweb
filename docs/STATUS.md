# Status

The site is now a world atlas. The gameplay engine, worker, and campaign UI have been removed. The map shows Natural Earth country and administrative-level-1 geometry, with source-based country ownership. Search, selection, pan, zoom, and a region list are available.

See README.md for data provenance and local commands. Earlier gameplay design documents in this directory are historical and no longer describe the app.

Zoom rendering correction, 2026-11-25: regenerated ADM1 data with D3-compatible polygon winding and six-decimal coordinates. State borders now appear over the map without filling the ocean. Two browser tests pass locally.
