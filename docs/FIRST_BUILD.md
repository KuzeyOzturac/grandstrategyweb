# First build contract

Player countries: Türkiye, Iran, Syrian government. Syrian opposition is an explicitly aggregated AI actor. Other regional countries participate through budgets, relations, access and crises; USA/Russia act as external guarantors. No later factions spawn on historical dates.
Global map, regional ADM1 boundaries, smaller Syrian military areas. Separate ownership/control. Army selection, objective, manual move, border assignment and halt; automatic routing, supply, combat and retreat. Simplified air support missions. Maritime pressure affects imports and port supply.
Diplomacy: relations, trade/access, guarantees, resource aid, sanctions, finite crises with reasons and costs; concession, escalation, backdown, intervention and settlement. Existing Syrian conflict can be mediated. Ceasefire must halt combat.
Economy: taxes, civilian/defence allocation, mobilization, industry/depot production investments, energy/civilian goods/fuel/equipment, treasury/debt, support/stability. Civilian harm/displacement and damaged infrastructure feed back to budgets and diplomacy.
Optional tutorial and sandbox; no forced end after one year. Defeat summary and observer mode. Local save/load and validated file import/export.
Acceptance: start all 3 countries; successful and failed negotiations; movement/combat/retreat/control; cut supply; deliver aid through a valid route; ceasefire; exact state roundtrip; seeded AI soak; desktop browser controls; deployed Pages smoke.
Not included: multiplayer, detailed navy, cyber/missile targeting, nuclear use, individual companies, detailed population occupations, elections/coups, freehand front drawing, playable opposition. These are deliberate exclusions, not inactive buttons.
